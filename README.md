# 🎨 Design e Estilização CSS - Semana 06

Nesta etapa, o portal do IFSP Pirituba recebeu uma camada de estilo profissional, separando a estrutura HTML da apresentação visual.

## 🚀 Novidades Técnicas
- **Menu Dropdown**: Navegação compacta e moderna para a lista de cursos.
- **Folha de Estilos Externa**: Uso de `menu.css` para padronizar todas as 10+ páginas do site.
- **Efeitos de Hover**: Interatividade visual em botões e links.
- **Estilização de Formulários**: Campos de entrada com sombras, cores personalizadas e arredondamento.

## 🛠️ Principais Propriedades CSS
- `flexbox`: Alinhamento inteligente do menu.
- `position: absolute/relative`: Construção do sistema de dropdown.
- `border-radius`: Elementos circulares e bordas suaves.
- `box-shadow`: Efeito de profundidade em containers.

## 📂 Arquivos Atualizados
- Todos os arquivos HTML agora herdam estilos de `menu.css`.
- `index.html`: Banner estilizado e imagem de evento circular.
- `entrar.html` / `contato.html`: Formulários com design responsivo.
